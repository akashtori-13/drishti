# DRISHTI — 240-second video beat sheet

Hard limits (per event guide): under 240 seconds (over-length gets cut, not excused).
Name every team member. Credit third-party assets. English subtitles required.
No under-18 faces/voices/names. Show the thing working — demo, not slideshow.
Test the link in a private window. Name the 2026 challenge and the NASA datasets on camera.

## Beats (30s each)

**0:00–0:30 — Hook.** Team AKASHTORI, one line each (names on screen). "NASA's SPHEREx
photographs the entire sky every six months in 102 infrared colors. DRISHTI lines up
each visit so anyone can blink between them." Say the challenge name + "SPHEREx Quick
Release 2 from the NASA/IPAC Infrared Science Archive."

**0:30–1:00 — First blink.** Land on home, press the 3I/ATLAS chip. Aug vs Dec 2025,
same band. Drag the timeline, press Play. "Stars stay put."

**1:00–1:30 — The catch.** Switch to Difference: stationary stars cancel to gray, the
comet remnant pops. Flip Motion color, toggle Movers for the A→B vector. Read the
measured motion in ″/day.

**1:30–2:00 — It's real science.** Light curve, 6-band spectrum with error bars,
SkyBoT/MPC/Horizons/SIMBAD cross-links, original FITS link. Ground truth card:
"we recover M31, the Crab, Omega Centauri within 0.3 arcminutes before trusting anything new."

**2:00–2:30 — Hold up the sky.** Phone: Point-at-sky AR, compass + elevation HUD.
Then airplane mode ON: offline APK keeps blinking from cache. "Built for places where wifi dies."

**2:30–4:00 — Scale + close.** Sky map census (2,590 cells), dice roll into an unknown
field, candidates page with σ-ranked cards. "Every measurement is public JSON any app
can reuse." Credits roll: IRSA/IPAC, CDS, ESA Gaia, IMCCE, CelesTrak, fonts, mirrors.
Team names again. End card: repo + release links.

## Fallback branch (hardware dies)

Skip to the cached About page: Method, Ground-truth table, Sources — all offline
after first visit. Narrate the same beats over those sections. Never stall silently on stage.
